Connected version: retrieval plan

1. Read the specified story

Follow relevant linked context, preserving scope and version.

2. Retrieve permitted knowledge

Search only authorized sources for the same feature, API, customer segment and release.

3. Show evidence and limits

Return source IDs, sections and dates. Show missing access or incomplete coverage honestly.

4. Keep internal material internal

Permission to read is not permission to publish.
